# Edu Mentor AI — ML Syllabus (v1)

## Module 1: Introduction to Machine Learning
- What is ML vs traditional programming
- Types: supervised, unsupervised, reinforcement
- Training, validation, and test sets

## Module 2: Supervised Learning
- Regression and classification
- Linear regression, logistic regression
- Decision trees and random forests

## Module 3: Unsupervised Learning
- Clustering (K-means)
- Dimensionality reduction (PCA)
- Anomaly detection basics

## Module 4: Neural Networks
- Perceptrons and activation functions
- Backpropagation and gradient descent
- CNNs and RNNs overview

## Module 5: Model Evaluation
- Accuracy, precision, recall, F1
- ROC-AUC, confusion matrix
- Cross-validation and bias-variance tradeoff

## Module 6: Practical ML
- Feature engineering and scaling
- Overfitting and regularization
- Hyperparameter tuning

## Module 7: Deployment Basics
- Model serialization
- Inference pipelines
- Monitoring drift

Place PDFs for each module in `data/ml-content/raw/` and run:
```bash
python scripts/ingest_ml_content.py
```
